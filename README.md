pen.ta.gram — GEOMETRIE
Nur Geometrie. Kein Text darüber hinaus.

1 · PUNKT
P = (x, y, z)
HOME = (0, 0, 0)
Ein Punkt hat Lage. Keine Richtung. Keine Länge.

2 · VEKTOR
v = (dx, dy, dz)
|v| = √(dx² + dy² + dz²)
Ein Vektor hat Richtung + Länge. Kein Ort, bis er an einen Punkt gehängt wird.

P' = P + v
3 · GERADE
P(t) = P0 + t · v
t ∈ ℝ
Eine Gerade ist ein Punkt + ein Vektor, in beide Richtungen verlängert.

t = 0   → P0
t = 1   → P0 + v
t = -1  → P0 - v
4 · STRECKE
P(t) = P0 + t · v
t ∈ [0, 1]
Eine Strecke ist eine Gerade mit Anfang und Ende.

5 · EBENE
9 × 9 = 81 Punkte
Eine Ebene ist 81 Punkte in einem Raster.

i = 1–9  → Zeile
j = 1–9  → Spalte
k = 1–9  → Ebene
6 · WÜRFEL · 729
9 × 9 × 9 = 729 Punkte
Adresse: i-j-k
Position: (k−1)×81 + (i−1)×9 + (j−1)

7 · KORRIDORE
X: 1-j-k → 9-j-k
Y: i-1-k → i-9-k
Z: i-j-1 → i-j-9
Drei Geraden durch jeden Punkt. Senkrecht zueinander.

8 · DIAGONALEN
45°: i = j
90°: i = k
Zwei weitere Geraden durch jeden Punkt. Schräg durch den Würfel.

9 · KREIS
(x − xm)² + (y − ym)² = r²
Mitte + Radius. Alle Punkte gleich weit von der Mitte.

10 · PENTAGRAMM
Mitte: 1 Punkt
Außen: 5 Punkte
Kanten: 5 Geraden
p1 → p3 → p5 → p2 → p4 → p1
Jede Gerade verbindet 2 Außenpunkte. Kein Punkt wird ausgelassen. Kein Punkt wird doppelt verbunden.

Zahlen an den Punkten:

Mitte: 41
Außen: 1 · 3 · 6 · 9 · 27
Geometrie trennt von Zahl:

Rolle: Mitte / Außen
Zahl: 41 / 1 / 3 / 6 / 9 / 27

14 · ABSTAND
d = √((x2−x1)² + (y2−y1)² + (z2−z1)²)
Abstand ist Länge einer Strecke zwischen 2 Punkten.

15 · MITTE
M = ((x1+x2)/2, (y1+y2)/2, (z1+z2)/2)
Mitte ist halber Weg zwischen 2 Punkten.

16 · SPIEGELUNG
P' = 2·M − P
Punkt an Mitte gespiegelt. Abstand bleibt gleich. Richtung kehrt um.

17 · DREHUNG
90°: (x, y) → (−y, x)
180°: (x, y) → (−x, −y)
360°: (x, y) → (x, y)
720°: 2 × 360°
Drehung um Mitte. Abstand zur Mitte bleibt gleich.

18 · SKALIERUNG
P' = M + s · (P − M)
s = Faktor
s = 1   → gleich
s = 3   → 3× weiter von Mitte
s = 1/3 → 3× näher an Mitte
19 · PRÜFUNG
Punkt gültig, wenn: 1 ≤ i ≤ 9, 1 ≤ j ≤ 9, 1 ≤ k ≤ 9
Gerade gültig, wenn: v ≠ (0, 0, 0)
Kreis gültig, wenn: r > 0
